# Idea 1
## Game Description
A intergalactic trade tycoon simulation. In this game players would be able to manage and create interplanetary trade routes, optimize production of resources, and handle economic and political challenges / strategies.
## Target Audience
- strategy game enthusiasts: want engaging strategy / sense of action
- science fiction fans: want engaging world and feeling of exploration
- resource management / economic simulation fans: want good trading / resource gathering mechanics 
## Key Stakeholders
- players: want engaging mechanics, balanced difficulty and re-playability
- game developers: need clear requirements for visual design and features of the game
- publishing company: need clear monetization strategy (DLC's, in-game purchases)
- legal / regulatory bodies: ensure game obeys gambling laws if ingame currency is involved, and make sure game obeys requirements of content rating (PG)
